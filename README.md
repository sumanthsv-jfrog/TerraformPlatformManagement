# JFrog Platform — Terraform Management

> Manage JFrog Artifactory, Xray, and Curation policies as Infrastructure as Code using Terraform.

---

## Overview

This repository contains Terraform configuration and tooling to manage a JFrog SaaS or self-hosted instance. It supports importing existing resources (brownfield) and creating new ones going forward.

### Providers Used

| Provider | Source | Version | Manages |
|----------|--------|---------|---------|
| artifactory | `jfrog/artifactory` | `~> 12.0` | Repositories, Users |
| platform | `jfrog/platform` | `~> 2.0` | Groups, Permissions |
| xray | `jfrog/xray` | `~> 3.1` | Xray Policies, Watches, Curation |

## Prerequisites

- Terraform >= 1.5
- `curl` and `jq` (for the import script)
- JFrog access token with Admin role

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-org/jfrog-terraform.git
cd jfrog-terraform
```

### 2. Create terraform.tfvars

```bash
cat > terraform.tfvars << 'EOF'
jfrog_token = "your-actual-token-here"
EOF
```

> ⚠️ `terraform.tfvars` is gitignored. Never commit your token.

### 3. Update providers.tf with your JFrog URL

```hcl
provider "artifactory" {
  url          = "https://YOUR-ORG.jfrog.io"
  access_token = var.jfrog_token
}
```

### 4. Initialize Terraform

```bash
terraform init
```

## Importing Existing Resources (Brownfield)

Use the import script to bring all existing JFrog resources under Terraform management.

### Step 1 — Run the import script

```bash
export ARTIFACTORY_URL="https://your-org.jfrog.io"
export ARTIFACTORY_TOKEN="your-access-token"

chmod +x GeneratePlatformImports.sh
./GeneratePlatformImports.sh
```

**Sample output:**

```
╔══════════════════════════════════════════════════╗
║    JFrog Terraform Import Generator              ║
╚══════════════════════════════════════════════════╝

⏳ Fetching repositories...   ✅ 953 repos imported (11 skipped)
⏳ Fetching users...          ✅ 165 users imported (1 system users skipped)
⏳ Fetching groups...         ✅ 50 groups imported
⏳ Fetching permissions...    ✅ 42 permissions imported
⏳ Fetching Xray policies...  ✅ 79 Xray policies imported (0 skipped)
⏳ Fetching Xray watches...   ✅ 24 Xray watches imported
⏳ Fetching curation conditions... ✅ 9 imported
⏳ Fetching curation policies...   ✅ 29 imported
════════════════════════════════════════════════════
  Total import blocks       : 1351
  Output file               : imports.tf
════════════════════════════════════════════════════
```

### Step 2 — Generate full HCL config

```bash
terraform plan -generate-config-out=existingimported.tf
```

### Step 3 — Apply known fixes

These three fixes are always needed due to provider limitations and legacy JFrog data:

```bash
# Fix 1 — xray policy description null → ""
sed -i '' '/resource "xray_.*_policy"/,/^}$/ s/  description = null/  description = ""/g' existingimported.tf

# Fix 2 — sast min_severity "unknown" → "All severities"
sed -i '' 's/min_severity = "unknown"/min_severity = "All severities"/g' existingimported.tf

# Fix 3 — sast "All severities" → "High" inside sast blocks only (awk)
awk '
/sast \{/ { in_sast=1 }
/\}/ { in_sast=0 }
in_sast && /min_severity = "All severities"/ {
    sub(/min_severity = "All severities"/, "min_severity = \"High\"")
}
{ print }
' existingimported.tf > existingimported_fixed.tf && mv existingimported_fixed.tf existingimported.tf
```

> **Note for Linux:** Remove the `''` after `-i` in the sed commands (`sed -i 's/...'`)

### Step 4 — Apply

```bash
terraform plan    # verify — should show 0 to destroy
terraform apply
terraform plan    # confirm — should show No changes
```

## Creating New Resources

Add new resource blocks to the appropriate `.tf` file and apply.

### Repository

```hcl
# repos.tf
resource "artifactory_local_generic_repository" "my_repo" {
  key         = "my-new-repo"
  description = "Created by Terraform"
}
```

### User

```hcl
# users.tf
resource "artifactory_unmanaged_user" "my_user" {
  name     = "john.doe"
  email    = "john.doe@company.com"
  password = "TempPassword#123!"
}
```

### Group

```hcl
# groups.tf
resource "platform_group" "my_group" {
  name        = "developers"
  description = "Developer group"
}
```

### Xray Security Policy

```hcl
# xray_policies.tf
resource "xray_security_policy" "my_policy" {
  name        = "my-security-policy"
  description = ""
  type        = "security"
  rule {
    name     = "high-severity-rule"
    priority = 1
    criteria {
      min_severity = "High"
    }
    actions {
      block_download { active = true }
      fail_build    = true
    }
  }
}
```

### Curation Policy

```hcl
# curation_policies.tf
resource "xray_curation_policy" "block_malicious" {
  name                  = "block-malicious"
  condition_id          = "1"
  scope                 = "all_repos"
  policy_action         = "block"
  waiver_request_config = "forbidden"
}
```

Then run:

```bash
terraform plan    # preview
terraform apply   # apply
```

| Release Bundles | — | — | System-managed, skipped |
| BuildInfo repos | — | — | System-managed, skipped |

## Known Provider Fixes

| Error | Fix |
|-------|-----|
| `description: was null, but now ""` | Set `description = ""` in xray policy resources |
| `min_severity = "unknown"` rejected | Replace with `"All severities"` |
| `"All severities" not valid in sast` | Replace with `"High"` inside sast blocks using awk |
| `tag_retention must be >= 1` | Replace `tag_retention = 0` with `tag_retention = 1` |

## Useful Commands

```bash
# Count resources in state
terraform state list | wc -l

# Apply only one specific resource
terraform apply -target=xray_curation_policy.my_policy

# Preview what would be destroyed
terraform plan -destroy

# Upgrade providers
terraform init -upgrade

# Check supported attributes
terraform providers schema -json | jq '.provider_schemas."registry.terraform.io/jfrog/xray".resource_schemas.xray_curation_policy.block.attributes | keys'
```

## State Storage

By default state is stored locally in `terraform.tfstate`. For team use, configure the JFrog Terraform Backend:

```hcl
# providers.tf
terraform {
  backend "remote" {
    hostname     = "your-org.jfrog.io"
    organization = "terraform-state-repo"
    workspaces {
      name = "jfrog-platform"
    }
  }
}
```

```bash
terraform login your-org.jfrog.io  # authenticate once
terraform init                      # migrates state to JFrog
```
